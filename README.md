# transformer-expressivity

Code for *The Expressive Power of Low Precision Softmax Transformers with (Summarized) Chain-of-Thought* (Brösamle & Eckstein, ICML 2026).

- [`turingformer/`](turingformer/) — Turing-machine constructions from Section 3 (CPU).
- [`sudoku/`](sudoku/) — Sudoku reasoning experiments from Section 5 (GPU).

See each subdirectory's README for setup and usage. MIT licensed.
